## Python Environment
- Python 3.10, managed via conda: `conda activate diffalign-10`
- ALWAYS use `python` from the activated conda env — never `python3` from system
- Install packages with: `conda install` or `pip install` (inside the env)
- Run scripts with: `python scripts/train.py` (not `python3`)
